##ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

###1. Encapsulation
    In the given situation, it relates to encapsulation in a way that it protects inventory information such as products, prices, and stocks. This allows the data protection and organization improvement.
###2. Abstraction
    Abstraction shows only the essential parts needed to simplify inventory operations. In this way, adding, removing, and searching, which are a methods involved in this specific concept, are used to help reduce complexity and improve maintainability.
###3. Inheritance
    Inheritence becomes crucial in creating different product types, such as food, toiletries, and drinks, which are all prodducts or items within the sari-sari store. This practices promotes code reuse and organization.
###4. Polymorphism 
    For a sari-sari store, polymorphism helps handle difficult product types using the same methods, such as displaying or on restocking items. This gives flexibility and reduces repeated code. 

##Reflection 
I believe that they are highly connected to each other. However, if I had to choose which concept would be the most useful in improving the stores' inventory system, I would choose abstraction. Abstraction shows only the essential features while hiding the complicated parts. This can help in making the inventory system easier to use and understand. It can also reduce complexity and save time when managing the sari-sari store.
